# DataLens Desktop

Official desktop builds for [DataLens](https://datalens.world). Fast, standalone access to your workspaces, datasets, and reports on Windows, macOS, and Linux.

---

## Downloads

Download the latest installer for your system from the **[Releases](https://github.com/alotautomations/datalens-desktop/releases)** page:

* **Windows:** `DataLens_0.1.0_x64-setup.exe`
* **macOS (Apple Silicon M1–M4):** `DataLens_0.1.0_aarch64.dmg`
* **macOS (Intel):** `DataLens_0.1.0_x64.dmg`
* **Linux:** `datalens_0.1.0_amd64.deb` or `DataLens_0.1.0_amd64.AppImage`

---

## Quick Setup Notes

### macOS
If macOS shows an unverified developer or damaged warning on first open:
1. Open **System Settings** → **Privacy & Security**.
2. Scroll to the Security section and click **Open Anyway**.
*(Or open Terminal and run: `xattr -cr /Applications/DataLens.app`)*

### Linux
* **Debian / Ubuntu:** Double-click the `.deb` file or run `sudo dpkg -i datalens_0.1.0_amd64.deb`.
* **AppImage:** Right-click the `.AppImage` → **Properties** → **Permissions** → enable **Allow executing file as program**, then double-click to launch.

### Windows
If Windows SmartScreen displays *"Windows protected your PC"*:
1. Click **More info**.
2. Click **Run anyway** to launch the installer.
